# Product Overview

Manager API is a REST API for authentication and user management. It provides:

- User registration (sign-up) and login (sign-in) via JWT-based authentication
- Authenticated user profile retrieval
- Health check endpoint
- Swagger/OpenAPI documentation served at `/docs`

The API is built with NestJS and uses PostgreSQL via Prisma ORM. Validation messages and error strings are written in Brazilian Portuguese (pt-BR).
